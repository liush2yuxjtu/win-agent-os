# 东升科技园点餐（Dongsheng Meal）

给用户推荐东升科技园（园区食堂 + 周边 500m 商圈）的午餐/晚餐菜品。本技能是**菜单查询与推荐助手**，不记账、不订餐、不接入真实商户。

## 数据

- 菜单文件：`assets/menu.json`（技能自带，14 道示例菜）。
- 每条菜品字段：`id` `name` `shop`（档口/店铺）`category`（套餐/面食/快餐/米线/轻食/饺子/小吃/热炒）`price` `spicy`（不辣/微辣/中辣）`tags` `calories` `recommend_for`。
- 数据是 AI 生成的示例，**不是真实商家菜单**；回复时如需可轻描淡写说明来源，不要让用户误以为是实时真实菜单。

## 执行步骤

1. **读数据**：读取 `assets/menu.json` 的 `items` 数组。
2. **收集约束**：从用户的话里提取过滤条件（可缺省）：
   - 口味偏好：辣（→ spicy 含"辣"）/ 不辣 / 清淡（tags 含"清淡"|"低卡"）
   - 预算上限：按 `price ≤ 上限` 过滤
   - 忌口/偏好：如"不想吃面"排除 category 含"面"、"减脂"优先低卡、"赶时间"优先快餐/套餐
3. **轮换避免重复**：若用户提到"昨天吃过/别重复"，或在对话中已知近期吃过的菜，排除或降权最近推荐过的 `name`。
4. **筛选出候选**：满足全部约束的菜品；若无候选则放宽（去掉最不关键的约束）并说明放宽了什么。
5. **推荐输出**：按以下优先级排序后取 Top 1 主推 + 2~3 个备选：
   - 明确偏好匹配 > 价格低 > 热量适中(380~750) > 有 recommend_for 场景匹配
6. **给出理由**：每条推荐必须带 1 句理由（价格/口味/热量/场景），让用户能直接决定。

## 输出格式

ALWAYS 按这个模板回复：

```
推荐你吃：【主推菜名】（店铺｜¥价格）
理由：一句话理由

备选：
- 备选1（店铺｜¥价格）－ 一句话理由
- 备选2（店铺｜¥价格）－ 一句话理由

（数据为示例菜单，来源：assets/menu.json）
```

若用户只问"菜单里有什么"，改为直接按 category 分组列出全部菜品（名称 + 价格），不做推荐。

## 边界

- 不接真实商户、不查 QC 业务库、不产生任何写库/下单动作；纯读本地 JSON + 规则推荐。
- 数据陈旧或字段缺失时如实说明，不编造菜品价格。
- 用户说"不用推荐，我要 XXX"时直接确认该菜存在与否；不存在则列出同 category 替代。
