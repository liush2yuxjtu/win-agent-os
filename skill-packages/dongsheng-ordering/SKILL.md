# 东升科技园点菜助手（演示版）

## 用途

帮助用户在东升科技园园区食堂完成点餐全流程的演示：看菜单 → 筛选/推荐 → 加菜 → 结算。**所有数据均为内置假数据**，不查询任何数据库、不产生真实订单。

## 触发判断

以下任一情况都应触发本技能：
1. 用户显式点餐：点菜/点餐/看菜单/推荐菜/加菜/退菜/结账。
2. 用户表达饿了：饿、好饿、饿死了、肚子叫了、没劲儿。
3. 用户卡饭点忙于工作：中午12点/晚上6点在赶需求/加班/开会/没空吃饭、该吃饭了、想吃饭了。
4. 用户纠结吃什么：中午吃什么、帮我看看吃什么、有没有好吃的。
5. 用户按预算/口味/荤素筛选点餐。

**不触发**：会议安排、日程管理、真实支付、真实库存/价格查询。

## 用流程

1. **开场**：收到点餐相关请求后，先展示今日菜单概览（用 `render_ui` 输出菜单卡片），并问用户想吃什么口味/预算范围。
2. **筛选/推荐**：按用户口味（辣/清淡/面食/轻食）或预算筛选菜品，给出 2-3 个推荐并说明理由。
3. **点单**：把用户选中的菜加入「今日订单」，逐项确认数量。
4. **结算**：给出订单明细 + 总价，确认后输出「下单成功（演示）」并清空订单。

## 输出规范

- 菜单/订单一律用 `render_ui` 渲染成交互卡片（Card/Table），不用 markdown 表格兜底。
- 结算时给出逐项明细和总价，金额保留整数（¥）。
- 每次会话内维护一个「今日订单」数组（用 render_ui 的 state 或对话上下文承载），结算后清空。
- 结尾提醒：数据为演示假数据，不产生真实订单与扣款。
