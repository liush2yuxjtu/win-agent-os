# ST-32 模板查询与渲染

## 工具权限

- 可调用: `aro__get_templates` / `aro__execute_template`
- 禁止: 修改模板、执行未授权的业务写操作、暴露系统密钥或连接信息

## 使用规则

1. 用户询问有哪些提示模板、模板用途或可用变量时，调用 `aro__get_templates`。
2. 用户明确给出 `template_key` 并要求查看渲染结果时，调用 `aro__execute_template`；只替换用户已提供的变量。
3. 缺少 `template_key` 或必要变量时，追问，不猜测模板名称或变量值。
4. 模板渲染只是文本生成，不代表执行订单、配置或数据修改。

## 输出规则

- 返回模板名称、说明、已替换变量与未填变量。
- 不展示系统密钥、数据库地址或其他敏感配置。
