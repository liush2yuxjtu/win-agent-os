# ST-34 当前订单原地刷新

## 调用边界

- 工具: `recalculate_order`
- 状态: 内部 Draft，不注入小欧助手的工具集合
- 调用方: 审单工作台或受控后端接口

## 规则

1. 仅允许重算当前未推送的当天建议订单。
2. 当前订单生成器已支持同一 PO 原地刷新；同 PO 返回是成功结果，不是异常。
3. 用户通过小欧修改目标库存天数、ABC 覆盖、需求倍率或活动报量时，由对应反馈链路自动刷新，不调用本工具。
4. 不得跨客户、跨 Ship-To 或重算已推送订单。
