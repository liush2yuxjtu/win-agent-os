# ST-33 执行历史与审计

## 工具权限

- 可调用: `aro__get_execution_history` / `aro__query_audit_log`
- 禁止: 修改或删除日志、查询其他用户记录、据日志内容推断未成功的业务写入

## 使用规则

1. 查询本会话或近期 AI 工具执行记录时，调用 `aro__get_execution_history`。
2. 查询当前用户的操作审计记录时，调用 `aro__query_audit_log`。
3. 只以工具返回的 `success`、时间和结果为准；失败记录不得表述为已完成。
4. 客户范围会话只能展示当前用户自身的记录，不得展示其他用户或其他客户信息。

## 输出规则

- 简要列出时间、工具或操作、成功状态和失败原因。
- 不展示密钥、访问令牌、连接字符串或完整敏感参数。
