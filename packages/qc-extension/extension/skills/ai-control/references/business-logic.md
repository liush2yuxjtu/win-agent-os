# ai-control 业务逻辑全解

---

## 一、业务名词解释

| 名词 | 含义 |
|------|------|
| **品线** | 产品线，如"好奇桃桃"、"护舒宝液体卫生巾"，每条品线有独立的基线ROI和基线日消耗 |
| **基线ROI** | 品线的ROI合格线（ROI_QUALIFIED_BASELINE），是判断素材"好/差"的核心标尺 |
| **基线日消耗** | 品线的日均消耗基准值（DAILY_SPEND_BASELINE） |
| **素材** | 一条投放视频素材，唯一业务键为 (ADVERTISER_ID, MATERIAL_ID) |
| **在投** | 素材仍在投放中（最后活跃日在数据最新日期前1天内） |
| **已下架** | 素材已停止投放（最后活跃日超出数据最新日期前1天） |
| **追投** | 对表现好的素材追加投放预算（乘方调控），目的是放大优质素材的收益 |
| **追投消耗** | 追投产生的额外消耗（additional_cost），区别于自然消耗 |
| **自然消耗** | 素材不包含追投的基础消耗（natural_cost = BASIC_STAT_COST_FOR_ROI2） |
| **总消耗** | 自然消耗 + 追投消耗 |
| **整体ROI** | 成交金额 / 总消耗（含追投） |
| **净ROI** | 成交金额 / 自然消耗（不含追投），更能反映素材本身效率 |
| **结算ROI** | 基于净成交（1小时归因窗口）的ROI，比整体ROI更精准 |
| **追投计划** | 千川乘方调控中的一个追投任务（TASK_ID），包含预算、消耗、ROI |
| **预算跑空** | 追投计划当日消耗 = 预算，说明预算全部花完，有继续放量的需求未被满足 |
| **成交金额** | 支付成交金额（含优惠券），即 pay_order |
| **活跃天数** | 素材在分析周期内有消耗的天数 |
| **日均消耗** | 总消耗 / 活跃天数（单素材）或 总消耗 / 分析天数（整体） |
| **下架前7日ROI** | 素材下架前最后7天的成交/消耗，反映素材被下架时的实时表现 |
| **全周期ROI** | 素材整个投放期间的累计成交/累计消耗，可能被初期探索期拖低 |
| **日消耗提升空间** | 操作损失 + 操作潜在收益，即通过纠正错误操作每天可多消耗的金额 |
| **操作损失** | 错误操作导致的消耗流失（极差在跑 + 追投浪费 + 被错误下架），止损可收回 |
| **操作潜在收益** | 正确操作可增加的消耗（补充素材 + 合理追投），增收可获取 |
| **ROI分桶** | 按累计ROI将素材分为3类：优质(≥基线)、中等(1.0~基线)、极差(<1.0) |
| **健康度评分** | 账号运营质量的综合评分(0-100)，由追投准确性、预算利用率、计划执行效率、素材汰换及时性四维度加权 |
| **正确追投** | 素材ROI和日均消耗都达到品线基线，且已被追投（追投消耗>0），是追投策略的正确执行 |
| **未追投** | 素材ROI或日均消耗有任意一个未达到品线基线，且未被追投（追投消耗=0），是正确的不追投决策 |
| **正常追投计划** | 追投计划ROI达到基线且预算未跑空，计划运行正常无需干预 |

## 二、判断分析逻辑

### 2.1 在投/下架判断

素材最后活跃日 ≥ (在投判断基准 - 1天) → **在投**；否则 → **已下架**。

在投判断基准 = min(品线数据最新日期, 全局数据最新日期)，取较早者避免品线数据延迟时误判所有素材已下架。

### 2.2 追投判断标准

**只有整体ROI ≥ 基线ROI时才应追投。** 低于基线追投 = 放大亏损。

- ROI ≥ 基线 → 应追投，追投可放大收益
- ROI < 基线 → 不应追投，追投在放大亏损
- 不存在"追投不足"或"追投了但不够多"的概念

### 2.3 "表现差"判断标准

ROI在基线附近波动（如基线5.0，ROI在3.5-4.9）属正常波动，不算"差"。真正极差需满足：
- ROI极低(<1.0)，远低于基线
- 或消耗较高但ROI极低(总消耗≥100且ROI < 基线×0.5)

### 2.4 九维分析

#### 维度一：应追投但没追投 ✅

| 项 | 逻辑 |
|----|------|
| 识别 | 在投 AND 当日整体ROI ≥ 基线 AND 当日消耗 ≥ 基线日消耗 AND 追投消耗=0 |
| 业务含义 | 素材当日表现好且在投，但没追投放大收益，错失放量机会 |
| 预估日增消耗 | `当日消耗 × min(当日ROI / 基线ROI, 3)`（ROI越高追投比例越大，但不超过3倍自然消耗，防追投后ROI大幅回落） |
| 排序 | 按预估日增消耗降序 |

#### 维度二：不该追投但追投了 ⚠️

| 项 | 逻辑 |
|----|------|
| 识别 | 当日整体ROI < 基线 AND 追投消耗 > 0 |
| 业务含义 | 当日ROI低于基线，追投在放大亏损，追投消耗是浪费的预算 |
| 浪费金额 | 该素材全部追投消耗 |
| 排序 | 按追投消耗降序 |

#### 维度三：正确追投 ✅

| 项 | 逻辑 |
|----|------|
| 识别 | 当日整体ROI ≥ 基线 AND 当日消耗 ≥ 基线日消耗 AND 追投消耗 > 0 |
| 业务含义 | 素材当日ROI和消耗都达标，且已被追投，是当前追投策略中正确的部分，可作为标杆参考 |
| 排序 | 按追投消耗降序 |

#### 维度四：未追投 🔇

| 项 | 逻辑 |
|----|------|
| 识别 | (当日整体ROI < 基线 OR 当日消耗 < 基线日消耗) AND 追投消耗 = 0 |
| 业务含义 | 素材当日ROI或消耗有任意一个未达到基线，且未被追投，属于正确的不追投决策，无需操作 |
| 排序 | 按总消耗降序 |

> **维度一~四构成素材追投分类的全集**：所有在投素材按"当日ROI是否达标 × 当日消耗是否达标 × 是否追投"三维度划分，落入维度一(应追未追)、维度二(不该追追了)、维度三(正确追投)、维度四(正确不追投)四个互斥集合。其中维度一和维度二是需要行动的，维度三和维度四无需操作。

#### 维度五：追投计划执行分析 📊

计划级指标字段：消耗=`STAT_COST_FOR_OVERALL_ROI2_ASSIST`，实际ROI=`TOTAL_PREPAY_AND_PAY_ORDER_ROI2_ASSIST`，目标ROI=`PAY_ROI2_GOAL`（对比用），运行状态=`CONTROL_STAT`（"已暂停"=已停止）。**先按 `CONTROL_STAT` 排除已暂停计划**——历史有消耗不代表现在还在跑，5A/5B 只针对仍在运行的计划。

**无品线标签的计划**（直投/星选等，无法关联 QC_MONTAGE_PRODUCT）：不整体排除，用计划自身目标 `PAY_ROI2_GOAL` 作为达标参照（5A: 实际ROI≥目标ROI；5B: 实际ROI<目标ROI），并在报告中标注"以计划目标 ROI 为参照"。

**5A 好计划预算跑空**：
- 识别：计划在运行 AND 计划ROI ≥ 基线 AND abs(消耗 - 预算) < 1（消耗≈预算，完全跑空）
- 业务含义：高ROI计划预算不够，错失继续高ROI放量的机会
- 建议：追加预算，好计划不设上限

**5B 不良计划未及时停止**：
- 识别：计划在运行 AND 计划ROI < 基线 AND 消耗 > 0
- 业务含义：低ROI计划持续消耗，浪费预算
- 建议：立即停止

**5C 正常追投**：
- 识别：计划ROI ≥ 基线 AND abs(消耗 - 预算) ≥ 1（预算未跑空，消耗未触顶）
- 业务含义：追投计划ROI达标且预算未跑空，计划运行正常，无需干预
- 建议：维持现状，持续监控

> ⚠️ 追投计划表同一计划同一天有多条记录（每条对应一个MATERIAL_ID），但消耗/ROI/预算是计划级汇总值在每条上重复，**不能SUM，必须去重**（先按 TASK_ID+DATE_TIME 去重再分析）。
> **5A/5B/5C构成追投计划分类的全集**：所有在运行的追投计划按"ROI是否达标 × 预算是否跑空"划分，5A(好计划跑空)和5B(不良计划)需要行动，5C(正常追投)无需操作。

#### 维度六：长期极差应下架 🗑️

| 项 | 逻辑 |
|----|------|
| 识别 | **在投** AND (当日ROI < 1.0 OR (当日消耗≥100 AND 当日ROI < 基线×0.5)) |
| 业务含义 | 素材当日表现极差但仍占投放位，持续浪费消耗 |
| 注意 | 已下架素材不在此列表，只有仍在投的才需建议下架 |
| 每日可节约 | = 日均消耗 |
| 排序 | 按日均消耗降序 |

#### 维度七：被错误下架 🔄

| 项 | 逻辑 |
|----|------|
| 识别 | 已下架 AND **下架前7日**ROI ≥ 基线 AND 累计消耗 > 10元 |
| 业务含义 | 素材下架时仍表现优秀，但被过早下架，错失继续投放机会 |
| 下架前7日ROI | 最后活跃日往前7天(含当日)的成交/消耗；不足7天取全部投放天数 |
| 关键区别 | 用下架前7日ROI（反映下架时实时表现），不用全周期ROI（可能被初期探索期拖低）。即使全周期ROI≥基线，但下架前7日ROI<基线，说明下架时表现已下滑，下架是合理的 |
| 被错误下架日均损失 | 逐条 SUM(累计消耗 ÷ 投放天数)，不能用总消耗÷总天数（会低估高消耗素材、高估低消耗素材） |
| 排序 | 按累计消耗降序 |

#### 维度八：在投素材数量 📉

| 在投数 | 状态 | 标题 | 数字颜色 | 核心结论 |
|--------|------|------|---------|---------|
| < 200 | 严重不足 | "在投素材数量严重不足" | 红 | 显示"需大量补充" |
| 200-500 | 正常 | "在投素材数量" | 绿 | **不显示**（无需行动） |
| > 500 | 冗余 | "在投素材数量冗余" | 橙 | 显示"需清理低效" |

- **严重不足**：下架后没补充上新，素材池缩水，大量潜在付费人群无法触达。建议大量补充，优先恢复维度七中被错误下架的优质素材
- **正常**：素材池规模合理，覆盖面基本充足。建议优先恢复维度七素材，保持正常上新节奏
- **冗余**：可能含大量低效素材占位。建议清理维度六中极差素材，控制在投数在200-500区间

### 2.5 日消耗提升空间模型

```
日消耗提升空间 = 操作损失合计 + 操作潜在收益合计
```

**操作损失（日均，红色）**：

| 子项 | 计算 | 来源 |
|------|------|------|
| ① 极差在跑损失 | 维度六所有素材日均消耗之和 | 维度六 |
| ② 追投浪费 | 维度二所有素材追投消耗之和 ÷ 分析天数 | 维度二 |
| ③ 被错误下架损失 | 逐条 SUM(每条素材累计消耗 ÷ 投放天数) | 维度七 |

**操作潜在收益（日均，绿色）**：

| 子项 | 计算 | 来源 |
|------|------|------|
| ④ 补充素材收益 | 在投<200时: (200-在投数) × 账号平均单条素材日均消耗(=总消耗/天数/在投数)；否则0 | 维度八 |
| ⑤ 合理追投收益 | 维度一所有素材预估日增消耗之和 | 维度一 |

> **核心原则**：只算消耗量的机会损失/收益，不推算成交金额。追投必然拉低ROI，不能假设ROI不变来算增量成交。操作损失是"止损可收回"，操作潜在收益是"增收可获取"，两者相加就是提升空间。

### 2.6 ROI分桶（3类）

| 桶 | 条件 | 颜色 |
|----|------|------|
| 优质 | ROI ≥ 基线 | 绿 |
| 中等 | 1.0 ≤ ROI < 基线 | 橙 |
| 极差/零转化 | ROI < 1.0 | 红 |

分别统计每个桶的消耗总额/占比和素材数量/占比。

### 2.7 追投vs未追投对比

- 有追投素材（追投消耗 > 0）vs 无追投素材（追投消耗 = 0）
- 分别计算：消耗总额/占比、素材数/占比、平均单条消耗、平均ROI

### 2.8 健康度评分（运营指导用）

| 维度 | 权重 | 100分 | 60分 | 20分 |
|------|------|-------|------|------|
| 追投准确性 | 30% | 浪费占比<5% | 5-10% | >10% |
| 预算利用率 | 25% | 0条跑空 | 1-3条 | >3条 |
| 计划执行效率 | 25% | 0条不良 | 1-5条 | >5条 |
| 素材汰换及时性 | 20% | 0个极差 | 1-10个 | >10个 |

## 三、运营投放指导逻辑

### 3.1 指导原则

1. **必须基于诊断数据**：每条建议 = 当前数据 → 问题根因 → 具体操作
2. **先数据总结再按维度指导**：2-3句话概括核心问题
3. **颗粒度要细**：不是"停止低ROI追投"，而是"停止XX-6.30-桃桃-混剪-种草-卖点-安全的追投，日均节省1,106元"
4. **预期效果诚实**：
   - **确定收益**（停止追投节省的金额、下架释放的投放位）可以量化
   - **不确定收益**（启动追投后的增量成交、整体ROI提升）只能定性描述，不能线性推算
   - 正确表述："提高高质量素材的消耗占比，拉高账号高ROI部分的消耗权重，达到消耗和ROI双提高的目的，但幅度有限，需要持续监控和快速响应"

### 3.2 指导维度

| 维度 | 核心内容 |
|------|---------|
| 追投策略调整 | P0停止低效追投(确定节省) + P0释放预算追投高质量素材(渐进提升消耗结构) |
| 预算分配优化 | 释放→再分配方案：停止低ROI追投+暂停不良计划→将释放预算追投到高质量素材 |
| 素材汰换节奏 | P0下架极差素材(确定释放) + P1高效素材承接释放预算 + 汰换SOP(每周一查维度六，下架即补位) |
| 追投计划优化 | 好计划追加预算(不设上限) + 不良计划暂停 + 计划管理SOP(每日10点查ROI，连续3天ROI<基线×0.5直接暂停) |
| 账号健康度评估 | 健康度评分(100分制) + 改善优先级(P0立即/P1本周/P2持续) |

### 3.3 优先级规则

| 优先级 | 含义 | 典型操作 |
|--------|------|---------|
| P0 | 立即执行，有确定金额收益 | 停止低ROI追投、暂停不良计划 |
| P1 | 本周执行 | 下架极差素材、将释放预算追投到高质量素材 |
| P2 | 持续优化+监控 | 追加好计划预算、每日监控追投后ROI |

## 四、报告生成逻辑

### 4.1 生成方式

按 SKILL.md 执行步骤：获取品线配置（动态查表）→ 查询素材数据 → 九维分析 → 生成HTML → 输出文件。基线ROI、品线名、基线日消耗均从数据库自动获取。分析周期以全局数据最新日期为终点往前推。无消耗记录过滤后，先把口径事实（最新日期、样本量、品线覆盖）查清楚再下结论。

### 4.2 HTML报告结构（7大板块）

1. **Header**：品线名、基线ROI、分析周期、活跃素材数、在投素材数、整体ROI、总消耗、日均消耗(accent高亮)、追投消耗
2. **日消耗提升空间面板**（高亮置顶）：操作损失(红) + 操作潜在收益(绿) = 提升空间(accent)，三卡片并排，含3项损失明细和2项收益明细
3. **核心结论**（高亮置顶）：8格汇总卡片（应追投/不该追投/正确追投/未追投/极差应下架/被错误下架/追投计划执行/在投素材数量），语义色背景，accent橙色边框+光晕。正确追投、未追投、在投正常时对应卡片不显示（无需行动）
4. **图表区**（4格网格）：
   - 饼图：各ROI水平线消耗占比（优质/中等/极差3类）
   - 饼图：各ROI水平线素材数占比
   - 饼图：追投vs未追投消耗占比
   - 柱状图：追投vs未追投平均单条消耗&ROI对比
5. **Summary卡片**（8个）：维度一~八关键数字
6. **九维详情**：每个维度独立section，含表格+建议框
7. **关键发现**：5条insight，核心关键词accent色高亮

### 4.3 表格规则

- 超过10行默认折叠，"展示全部 N 条"按钮展开
- 素材名最大宽度240px，溢出省略
- ROI用圆角背景标签(badge)：绿底绿字(≥基线) / 红底红字(<1.0) / 橙底橙字(1.0~基线)
- 金额右对齐，逗号分隔
- 每个维度底部有彩色建议框，颜色与维度标签一致

### 4.4 视频播放

- 主路径：千川DOWNLOAD_URL（无需额外依赖）
- fallback：VIDEO_OSS_URL + 阿里云OSS签名（有效期7天，过期需重新生成报告）
- 播放按钮在素材名**左侧**（避免长名称截断后按钮不可见）
- 弹层不设max-height/overflow:hidden（避免视频控制条被裁切）
- 适用维度：维度一、维度二、维度三、维度六、维度七的素材表格行

### 4.5 维度八条件渲染

- 响应式：@media(max-width:768px) 适配移动端

## 五、注意事项

| # | 事项 |
|---|------|
| 1 | 素材级指标唯一来源是 `千川素材数据_素材列表`，不经过CUT切片表 |
| 2 | (ADVERTISER_ID, MATERIAL_ID) 是关键业务键，两侧均为numeric类型，无需CAST |
| 3 | MATERIAL_ID必须保持精度：必须用str()转换，不能用int(float())——float会丢失19位大数末尾精度 |
| 4 | 追投计划表必须用品线素材筛选再去重：缺筛选→混入其他品线；缺去重→重复计算 |
| 5 | 中文编码：pymssql用charset='utf8'，中文字段需decode('gbk') |
| 6 | ROI计算用NULLIF避免除零 |
| 7 | cost=0的记录需过滤（数据延迟） |
| 8 | 预算跑空判断：abs(消耗 - 预算) < 1 |
| 9 | 历史数据不代表当前状态：预算未花完≠计划仍在运行，以 `CONTROL_STAT` 为准（"已暂停"即已停止） |
| 10 | ROI分桶为3类（优质/中等/极差），不用4类 |
| 11 | 补充素材收益用账号平均单条素材日均消耗(=总消耗/天数/在投数)，不用固定基线值 |
| 12 | 在投判断基准 = min(品线最新日期, 全局最新日期)，避免品线数据延迟时误判 |
| 13 | 被错误下架日均损失必须逐条计算(累计消耗÷投放天数再求和)，不能用总消耗÷总天数 |
| 14 | 维度七用下架前7日ROI判断，不用全周期ROI——素材可能在投放初期表现差(探索期ROI低)但后期表现提升后仍被下架 |
| 15 | 追投必然拉低素材ROI（加价放量，单位效率下降），不能假设ROI不变来算增量成交 |
| 16 | 维度六只包含在投素材，已下架的极差素材不需要再建议下架 |
| 17 | 维度八在投正常时，核心结论中不显示在投数量卡片（无需行动） |
| 18 | 维度一~四构成素材追投分类全集：维度一(应追未追)+维度二(不该追追了)需行动，维度三(正确追投)+维度四(正确不追投)无需操作 |
| 19 | 维度五5A/5B/5C构成追投计划分类全集：5A(好计划跑空)+5B(不良计划)需行动，5C(正常追投)无需操作 |
| 20 | 维度一"应追投"的条件：当日ROI ≥ 基线 **且** 当日消耗 ≥ 基线日消耗；仅ROI达标但消耗不达标的不算"应追投"，归入维度四"未追投" |
| 21 | 乘方调控表没有 `COST`/`ROI` 列：消耗=`STAT_COST_FOR_OVERALL_ROI2_ASSIST`，实际ROI=`TOTAL_PREPAY_AND_PAY_ORDER_ROI2_ASSIST`；素材列表整体ROI=`TOTAL_PREPAY_AND_PAY_ORDER_ROI2`，追投消耗=`ADDITIONAL_DELIVERY_STAT_COST_FOR_ROI2_ASSIST`，追投ROI=`ADDITIONAL_DELIVERY_TOTAL_PREPAY_AND_PAY_ORDER_ROI2_ASSIST` |
